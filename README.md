### [Clishe](https://github.com/Sym-jay/clishe) &nbsp;·&nbsp; Python, Bash

An offline-first command-line companion for Linux beginners. Type plain English, see the exact
command before it runs, and learn the shell as you go. AI is optional and runs locally through
Ollama — nothing leaves the machine unless you turn on a cloud provider deliberately.

### [Polyphage](https://github.com/Sym-jay/polyphage) &nbsp;·&nbsp; Python

Multi-objective computational design of IsPETase variants for PET-plastic degradation.
ProteinMPNN proposes sequences against a fixed backbone with the catalytic triad frozen,
ThermoMPNN prices the stability cost of each mutation, and NSGA-II returns a Pareto front
instead of a single "best" answer.

<p>
  <img src="https://img.shields.io/badge/replication-20%20seeds-555555?style=flat-square" alt="20-seed replication">
  <img src="https://img.shields.io/badge/D186H%20recovery-2%2F20%20runs-555555?style=flat-square" alt="D186H recovered in 2 of 20 runs">
  <img src="https://img.shields.io/badge/p%20(Holm)-0.034-555555?style=flat-square" alt="p = 0.034 under the strictest null">
  <img src="https://img.shields.io/badge/license-MIT-555555?style=flat-square" alt="MIT">
</p>

The search recovers **D186H**, a published FAST-PETase thermostability mutation, with no access
to the paper — significant under every null tested, including a ddG prior weighted by both
position and residue. An earlier headline result that did not reproduce was withdrawn and
documented rather than quietly dropped.

### [WildID](https://github.com/Sym-jay/WildID) &nbsp;·&nbsp; Dart, Flutter, PyTorch

A mobile app that identifies endangered marine species from a photo, built for conservation
awareness in the Indo-Pacific region.

<p>
  <img src="https://img.shields.io/badge/accuracy-98.47%25-555555?style=flat-square" alt="98.47% accuracy">
  <img src="https://img.shields.io/badge/species-66%20CITES--protected-555555?style=flat-square" alt="66 CITES-protected species">
  <img src="https://img.shields.io/badge/models-3%20ensemble-555555?style=flat-square" alt="3-model ensemble">
</p>

EfficientNet-B0 as the primary classifier, with a ResNet-50 + MobileNet-V3 weighted-vote
ensemble and automatic fallback. Offline caching, confidence scoring, IUCN Red List linking,
and life lists.
